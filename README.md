# p-giakoumoglou.github.io

Personal academic website for Paschalis Giakoumoglou.

## Structure

- `index.html` — homepage, biography and news
- `publications.html` — publication list
- `style.css` — light/dark theme and responsive layout
- `theme.js` — day/night toggle with system-theme detection and saved preference
- `src/paschalis.jpg` — profile photo
- `src/cv.pdf` — downloadable CV

The site is plain HTML/CSS/JavaScript and can be hosted directly with GitHub Pages.
